# Workout Builder - Frontend Assignment

## Project Overview

The **Workout Builder** is a web application that allows users to build custom workout plans by dragging and dropping workout blocks. The app provides an interactive interface to create personalized workout routines and visualize them on a distance-based graph.

## Features

- **Drag-and-Drop Interface**: Users can drag and drop workout blocks to build their workout routine.
- **Workout Blocks**: The app includes various workout blocks like "Warm Up", "Active", "Cool Down", and more. Each block has a distance and fill percentage.
- **Multi-Step Blocks**: Some workout blocks (e.g., "Ramp Up", "Ramp Down") contain sub-blocks for more detailed workout sequences.
- **Interactive Graph**: The app visually displays the workout blocks on a graph, with distance and fill percentage represented graphically.
- **Clear and Save**: Users can clear the current workout or save the routine.

## Technologies Used

- **Next.js**: The app is built with Next.js, a React-based framework for server-rendered applications.
- **React**: The app uses React for building reusable UI components.
- **react-beautiful-dnd**: A library for drag-and-drop functionality.
- **Tailwind CSS**: A utility-first CSS framework used for styling.
- **Lucide Icons**: Icon library used for UI components.

## Installation

### 1. Clone the repository:

```bash
https://github.com/Rakeshmatta369/spur-fit-frontend
```

### 2. Install dependencies:
- Navigate to the project folder and install the dependencies:

```bash
cd workout-builder
npm install
```

### 3. Run the development server:
Start the local development server:

```bash
npm run dev
```
